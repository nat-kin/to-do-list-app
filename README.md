# To-Do List App 📝

A simple command-line to-do list manager in Python. Add, view, mark done, delete tasks—with saving to file!

## How to Run
1. `python3 todo.py` (or `python todo.py`)
2. Follow the menu prompts.

## Features
- Persistent storage (JSON file).
- Basic CRUD operations for tasks.
- Status tracking (done/pending).
